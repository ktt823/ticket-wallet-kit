# 票券 — 自己架一套

把票券截圖丟進去，自動讀出商家、券名、到期日和序號，依到期日排好，可以加到 iPhone／Android 主畫面當 App 用，也能勾幾張產生連結分享給別人。

這裡放的是**給朋友自己架一套**的檔案。架好之後，你的票券存在你自己的 Google 試算表、截圖存在你自己的雲端硬碟，給你這個網址的人看不到你的任何資料。

**目前版本：v94（2026-10-11）**

---

## 需要準備什麼

- 一台電腦，全部在瀏覽器裡做，第一次大約半小時。不用裝任何程式。
- Google 帳號：放票券和截圖。
- Cloudflare 帳號（免費）：放 App 的網站。安裝時再註冊就好。
- 一把辨識用的金鑰：Gemini（有免費額度）或 Claude（付費，一張截圖約 NT$0.1），安裝說明裡有申請方法。
- **不需要 GitHub 帳號**。這一頁只是拿來下載。

---

## 第一次：下載、安裝

1. 按這一頁上面綠色的「**Code**」按鈕 →「**Download ZIP**」。
2. 把下載的 zip 解壓縮，打開裡面的「**票券-自己架一套**」資料夾。
3. 打開 `安裝說明.pptx`，照著一頁一頁做（PowerPoint、Google 簡報、Keynote 都打得開）。
   - 在 GitHub 網頁上點 pptx 看不到內容，要下載下來才能開。
   - 想看文字版，或想知道更多用法，看同一個資料夾的 `README.md`。
4. 最後在手機上打開你自己的網址，「加到主畫面」就好。

---

## 以後有新版本

1. 你的 App 最上面會自己出現「**有新版本 vXX**」，點進去看得到這次改了什麼。
2. 回到這個網址，一樣「Code → Download ZIP」下載最新的（App 裡給的下載連結也可以，內容一樣）。
3. 照資料夾裡的 `更新說明.md` 做，大約 10 分鐘：
   - 後端：把 Apps Script 裡的 `Code.gs` 換成新的 → 儲存 →「部署 → 管理部署作業 → 鉛筆 → 版本選『新版本』→ 部署」。
     **不要按「新增部署作業」**，那會換網址，手機和 Cloudflare 都要重設。
   - 網站：Cloudflare 你的專案 →「Create new deployment」→ 把新的 `web` 資料夾整個拖進去。
   - 手機：App「設定」拉到最下面，按「強制更新到最新版」。
4. 你的票券、截圖、存取碼都不會動。

不確定這裡有沒有比你的新：看這一頁上面的「目前版本」，或 App「設定 → 版本」。

## 小提醒

- 安裝時拿到的 **OWNER_KEY（存取碼）**、`/exec` 結尾的後端網址、辨識金鑰，都不要貼到網路上或傳給別人。覺得外流了，到 Apps Script「專案設定 → 指令碼屬性」把 `OWNER_KEY` 改掉就好。
- 這一頁是公開的，只放程式，沒有任何人的票券或資料。
- 這一頁的 Fork、Star、Issues 都不用理，也不用註冊帳號。有問題直接問給你這個網址的人。
- `web/brands` 裡的店家 logo 商標屬各家所有，僅供自用；不想用的話把那個資料夾刪掉，會自動改成「第一個字＋品牌色」。
