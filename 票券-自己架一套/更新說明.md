# 票券 — 已經裝過舊版，怎麼更新

這份給**已經照「安裝說明」裝好一套**（Apps Script 後端 ＋ Cloudflare Pages 網站）的人。
不用重裝，你的票券、截圖、存取碼都會保留，只是把程式換成新版。

大約 5 分鐘，全部在電腦的瀏覽器裡做。

---

## 先知道三件事

1. **資料不會動。** 票券在你的 Google 試算表、截圖在你的雲端硬碟、金鑰和存取碼在 Apps Script 的「指令碼屬性」。更新只換兩樣東西：後端 `Code.gs`、網站 `web` 資料夾。
2. **兩邊都要換。** 只換一邊，App 會在列表上方提醒還差哪一邊。
3. **網站用「網站產生器」下載**（v98 起）：它會把你的後端網址填進網站，拖進 Cloudflare 就好，不用設 `EXEC_URL`、不用改任何檔案。以前設過 `EXEC_URL` 的留著也沒關係。

開始前先找出你的 `/exec` 網址（`https://script.google.com/macros/s/…/exec`），下面任何一個地方都找得到：
- 手機 App「設定 → 右上角鈴鐺 → 後端與存取碼」（舊版 App：「設定 → 後端與存取碼」）
- Apps Script 右上「部署 → 管理部署作業」裡的「網頁應用程式」網址

---

## 步驟 1　更新後端（Apps Script）

1. 打開你原本的「票券後端」專案。
2. 把左邊 `Code.gs` 的內容**全選刪掉**，貼上新包裡 `Code.gs` 的全部內容，按儲存（磁碟片圖示）。
   - 如果你以前改過檔案最上面的設定（例如 `MODEL`、`NOTIFY_` 開頭的通知開關），貼完要再改一次。
3. 上方函式選單選 `setup`，按一次「執行」。
   - 這是安全的：它不會動你現有的票券和存取碼，只會補上新版需要的東西、把每天早上的到期提醒排程裝好。
   - 如果跳出「需要授權」，就照畫面選你的帳號 →「進階」→「前往（不安全）」→ 允許。新版需要新的權限時會在這裡問你，要允許過，後端才會正常運作。
4. 右上「部署」→「**管理部署作業**」→ 點作用中那一筆右邊的**鉛筆** →「版本」選「**新版本**」→「部署」。

> **不要按「新增部署作業」。** 那會換一個新網址，手機 App 和網站都要重新設定。
> 用「管理部署作業 → 鉛筆 → 新版本」，網址不會變。

---

## 步驟 2　更新網站（Cloudflare Pages）

1. 下載「已經填好你後端網址的網站」，兩種方法都可以：
   - App 的「更新」頁按「**只下載網站（已經填好你的後端網址）**」（v98 以後的 App 才有這顆）
   - 或打開網站產生器 <https://tickets-37z.pages.dev/kit.html>，貼上你的 `/exec` 網址 →「下載你的網站」
2. 解壓縮，裡面有一個 `web` 資料夾。
3. 登入 <https://dash.cloudflare.com> →「**Workers 和 Pages**」→ 點你的專案 → 右上角藍色「**建立部署**」→ 把整個 `web` 資料夾拖進去 → 部署。
   - 英文介面：Workers & Pages → 你的專案 → Create deployment
4. 你的網站網址不會變。

---

## 步驟 3　手機上換成新版

1. 打開 App →「設定」，拉到最下面按「**強制更新**」。
2. 「設定」最下面的更新卡會寫版本，網站和後端是同一個新版本號就對了。
   - 如果你的舊版沒有「強制更新」按鈕：把主畫面的 App 關掉重開兩次；還是舊畫面的話，刪掉主畫面捷徑再重新「加到主畫面」。票券都在你的試算表裡，不會不見。

---

## 怎麼確認更新成功

1. 瀏覽器打開 `https://你的網址/s/test`：看到「這個分享連結不存在」→ 分享連結通了。
2. App「設定 → 右上角鈴鐺」最上面的「狀態」：後端、辨識、分享連結、通知都是綠點。
3. 有設 Discord 的話，同一頁按「傳一則測試通知」，看 Discord 有沒有收到。

之後有新版本時，App 最上面會自己提醒「有新版本」，每次都是重複**步驟 1、步驟 2、步驟 3**。

## 卡住的時候

| 看到 | 多半是 |
|---|---|
| 分享連結打開寫「還沒設定好」 | 網站還不知道後端網址：照步驟 2 用網站產生器重新下載、再「建立部署」一次 |
| 網站產生器說「這不像 Apps Script 的網址」 | 貼的要是 `https://script.google.com/macros/s/…/exec` 那一串，結尾是 `/exec` |
| App 上方提醒「還差後端」或「還差網站」 | 只更新了一邊，把另一邊也做完，再按「強制更新」 |
| 測試連線說「後端回傳的不是 JSON」 | 部署的「誰可以存取」不是「所有人」，或網址不是 `/exec` 結尾 |
| 測試連線說「存取碼不對」 | `OWNER_KEY` 貼錯，或前後多了空白 |
| 手機一直是舊畫面 | 按「強制更新」；還是不行就關掉 App 重開兩次，最後才刪掉捷徑重加 |
| 不小心按了「新增部署作業」，網址變了 | 用新的 `/exec` 網址到網站產生器重新下載網站、「建立部署」；App「設定 → 右上角鈴鐺 → 後端與存取碼」換成新網址 |
